## 摘要
随着记忆跨任务和会话不断积累，长期LLM智能体的性能既取决于针对具体查询的检索，也依赖于持续的记忆精炼。然而，现有方法通常要么优化记忆访问（通过迭代查询精炼或自适应检索策略），要么优化记忆演化（如结构更新）。这种分离忽略了一个基本的反馈循环：检索决定了哪些记忆会收到使用信号，而更新后的记忆库又会重塑未来的检索。我们提出\textbf{CoEvo-Mem}，一个用于协同进化检索策略与记忆库的闭环框架。对于每个查询，一个冻结的LLM生成路径特定的查询改写和路由先验，然后由一个轻量级残差路由器在线校正。检索到的上下文作为两个学习过程之间的耦合接口：任务结果为路由决策分配信用，而基于轨迹条件的反馈更新记忆值和图关系。这些更新改变了后续查询中记忆的排序和选择方式，从而闭合了反馈循环。为了缓解耦合导致的非平稳性，CoEvo-Mem 交替进行：在固定记忆库时更新路由器，以及在固定检索策略时演化记忆库。在七个不同的基准测试中，\textbf{CoEvo-Mem} 达到了最先进的性能，证明了检索与记忆协同进化的重要性。

## Abstract
As memories accumulate across tasks and sessions, the performance of long-term LLM agents depends jointly on query-specific retrieval and continual memory refinement. However, existing methods typically optimize either memory access, through iterative query refinement or adaptive retrieval policies, or memory evolution such as structural update. This separation overlooks a fundamental feedback loop: retrieval determines which memories receive usage signals, while updated memory bank reshape future retrieval. We propose \textbf{CoEvo-Mem}, a closed-loop framework for co-evolving the retrieval policy and memory bank. For each query, a frozen LLM generates route-specific query rewrites and a routing prior, which a lightweight residual router corrects online. The retrieved context serves as the coupling interface between the two learning processes: task outcomes assign credit to routing decisions, while trajectory-conditioned feedback updates memory values and graph relations. These updates alter how memories are ranked and selected for subsequent queries, thereby closing the feedback loop. To mitigate coupling induced non-stationarity, CoEvo-Mem alternates between updating the router with the memory bank fixed and evolving the memory bank with the retrieval policy fixed. Across seven diverse benchmarks, \textbf{CoEvo-Mem} achieves state-of-the-art performance, demonstrating the importance of retrieval-memory coevolution.

*   **整体含义（研究动机）**：论文指出，检索与记忆并非孤立组件，而是构成一个**闭环反馈回路**。检索决定了哪些记忆会被暴露出来、接收使用信号并获得反馈；而基于这些反馈的记忆更新（如改变记忆的效用值或关系结构），又会重塑未来检索时的排序和选择结果。单独优化其中一方，另一方将无法适应变化，从而导致整体系统性能的次优。因此，论文主张必须**联合优化检索策略和记忆库**，使其能够协同进化。

### 2. 论文提出的方法论

论文提出名为 **CoEvo-Mem** 的闭环框架，核心思想是在冻结基座LLM的前提下，让检索策略（由一个残差路由器实现）和结构化记忆库（关系型记忆图）通过交替更新的方式进行协同进化。

**关键技术细节：**

*   **路径特化查询改写的自路由查询重写器（SR-QR）**：
    *   一个冻结的LLM（F_route）接收用户查询，生成路径特化的输出：用于稠密检索的语义改写查询（eQd）、用于稀疏检索的关键词改写查询（eQs），以及一个分配稠密/稀疏路径权重的**路由先验（routing prior，p0）**。
    *   这种设计将查询中的语义意图和精确词汇线索分离，为后续混合检索奠定基础。
*   **先验引导的残差路由器**：
    *   这是一个轻量级的可训练模块，由查询编码器（φψ）和策略头（fω）组成。
    *   它接收原始查询和SR-QR的输出，学习一个**残差校正项（Δt）**。
    *   最终的路由策略（πt）是平滑后的LLM先验（¯p0）与残差校正项的Softmax组合：πt = softmax(log ¯p0 + Δt)。
    *   **学习方式**：使用**奖励驱动的强化学习**。以任务完成的奖励（Rt）作为信号，通过**得分函数估计器**（REINFORCE-style）训练路由器，同时加入一个**KL散度正则项**，防止路由策略过度偏离LLM的先验，保证了训练的稳定性。
*   **检索对齐的关系型记忆演化**：
    *   记忆被组织成一个**有类型关系图（Typed Relational Memory Graph）**。节点存储经验，边则有三种类型：稠密关系（语义相似）、稀疏关系（词汇重叠）和时间关系（时序先后）。
    *   **记忆效用学习**：采用类似**时序差分学习（TD-learning）** 的方式更新每个记忆的Q值（效用估计）。对于被检索到的记忆，其更新残差（δ）由“即时任务奖励×记忆贡献度 + 折后的后继记忆效用 - 当前效用”构成。新记忆的初始效用从上下文记忆的平均效用继承。
    *   **关系型信用传播**：不仅更新被直接检索到的记忆，还会沿着图的边（稠密、稀疏、时间关系）将**效用更新信用传播给相关的记忆**，实现了更高效的经验价值流动。
*   **交替协同进化**：
    *   为处理耦合训练带来的非平稳性问题，CoEvo-Mem采用**分阶段交替更新机制**。
    *   在 **“路由器阶段（Router Phase）”** ，固定记忆库，仅使用任务奖励更新残差路由器。
    *   在 **“记忆阶段（Memory Phase）”** ，固定路由器，使用轨迹反馈更新记忆图的内容、结构和效用值。
    *   二者交替进行，使每个组件的优化都能基于对方的最新状态，同时避免了在同一轨迹上同时更新两个组件带来的耦合噪声。

### 7. 优点

*   **新颖的闭环视角**：首次明确将检索策略与记忆演化建模为一个相互影响的耦合学习问题，并用闭环框架来解决，这是重要的思想贡献。
*   **优雅的方法设计**：
    *   **残差路由**：在强大的LLM先验上进行轻量级、奖励驱动的在线纠正，既利用了LLM的知识又避免了从零学习的不稳定。
    *   **检索对齐的记忆图**：记忆图的关系类型与检索通道（稠密、稀疏、时间）天然对齐，逻辑自洽。
    *   **关系型信用传播**：通过图结构将任务成功/失败的信号传播给相关记忆，比只更新被检索到的记忆更高效。
    *   **交替更新**：简单而有效地解决了耦合训练的非平稳性问题。
*   **全面的实验验证**：在7个跨度极大的基准测试上、与多种范式的大量基线方法进行了详尽对比，并对核心组件和训练策略进行了细致的消融分析，实验论证非常扎实。
*   **模块化与兼容性**：框架的关键优势在于基座回答模型（F_ans）是**冻结的**，这意味着CoEvo-Mem可以作为即插即用的记忆增强模块，与各种强大的LLM结合，而无需昂贵的微调。

### 8. 不足与局限

*   **模型角色分配的复杂性**：框架引入了多个LLM角色（回答、路由查询改写、记忆管理）。虽然这带来了灵活性，但不同角色间（尤其是F_ans和F_route）的模型能力组合对最终性能的影响未被充分探索，这可能是未来工作的方向，但当前作为“黑盒”使用，增加了系统设计的复杂度。
*   **计算与存储开销**：论文未深入讨论协同进化过程引入的额外计算和存储成本。特别是，在记忆阶段，每次交互都需要调用LLM进行记忆构建、效用归因和可能的元数据修复，这会增加推理和训练的延迟与成本。
*   **超参数敏感性**：框架引入了诸多超参数（如折现因子γ、衰减因子ρ、KL系数β等），论文虽未强调，但如此耦合的复杂系统，其性能可能对这些参数较为敏感。
*   **评估的局限性**：尽管评估基准多样，但主要集中在单一智能体执行定义明确的任务上。论文“未来工作”部分也承认，在多智能体记忆共享和异步更新等更复杂的动态场景下的有效性和理论保证尚待研究。
