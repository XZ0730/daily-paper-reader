## 摘要
现代推荐模型的优化仍然严重依赖工程师手动迭代架构、目标和训练策略的修改。尽管基于LLM的智能体可以自动化这一试错过程，但让LLM同时选择修改方向并生成具体假设，往往会在有限的实验预算下导致搜索过程不稳定。受此挑战启发，我们提出了RecHarness，一个基于Bandit路由的代理式工具，用于自动化推荐模型优化。RecHarness将优化过程分为两步：Bandit路由器根据历史验证反馈选择下一步的修改方向，而LLM则在选定方向内生成具体的优化假设和可执行的代码编辑。为维持长期探索，RecHarness采用跳跃盆地机制，在局部编辑停滞时激活结构跳跃臂。在多个推荐任务、数据集和模型骨干上，RecHarness比基于LLM推理的搜索实现了更稳定的性能提升，并更有效地利用了有限的试验预算。在一项针对大型短视频广告平台为期7天的在线A/B测试中，选中的候选方案使ADVV提升2.084%，收入提升0.534%，曝光量提升0.559%。代码已开源在https://github.com/6lyc/RecHarness。

## Abstract
Optimizing modern recommender models still depends heavily on engineers manually iterating over architectural, objective, and training-strategy changes. While LLM-based agents can automate this trial-and-error process, allowing the LLM to both select modification directions and generate concrete hypotheses often leads to unstable search under limited experiment budgets. Inspired by the above challenge, we propose RecHarness, a Bandit-Routed Agentic Harness for automated recommender model optimization. RecHarness separates the optimization process into two steps: a bandit router selects the next modification direction according to historical validation feedback, while the LLM generates a concrete optimization hypothesis and executable code edit within the selected direction. To sustain long-horizon exploration, RecHarness uses a jump-basin mechanism to activate a structural-jump arm when local edits stagnate. Across multiple recommendation tasks, datasets, and model backbones, RecHarness achieves more stable performance improvements and uses limited trial budgets more effectively than LLM-reasoning search. During a 7-day online A/B test on a large-scale short-video advertising platform, the selected candidate improves ADVV by 2.084%, Revenue by 0.534%, and Exposure by 0.559%. Code is available at https://github.com/6lyc/RecHarness.

现代推荐模型的优化仍高度依赖工程师手动迭代架构、目标函数和训练策略，过程耗时且难以系统探索。虽有基于大语言模型（LLM）的智能体尝试自动完成该试错过程，但直接将方向选择与具体代码生成全交给 LLM 决策，在有限的实验预算下会导致搜索方向不稳定、试验成功率低。本工作旨在构建一个能根据验证反馈自主演化推荐模型的代理式框架，在有限试验预算内稳定且高效地提升模型性能。

### 2. 论文提出的方法论：核心思想、关键技术细节
RecHarness 将优化过程分解为两级控制，核心是“Bandit 路由方向选择 + LLM 具体编辑生成”，并由实验技能与跳跃盆地机制辅助。

- **优化问题建模为 Bandit 问题**  
  搜索空间被定义为预定义的编辑臂集 \( A \)，分为局部臂 \( A_{\text{local}} \)（微调）和跳跃臂 \( A_{\text{jump}} \)（结构变迁）。每轮试验消耗有限预算，目标是找到实现 \( s^\star \) 最大化验证指标。采用基于当前最优版本（incumbent）的搜索，仅当候选方案超出历史最优时才提升版本。

- **Thompson 采样进行探索‑利用**  
  每条臂维护一个 Beta 分布后验 \( \text{Beta}(\alpha_a, \beta_a) \)，每轮采样成功率 \( \tilde{\theta}_a \)，选取 Top‑G 个臂作为本轮编辑方向。奖励定义为：候选有效、在组内标准化提升大于 0、且不低于历史最优为成功（1 奖励），否则失败。后验根据二值结果更新。该路由器决定“下一步往哪探索”，使试验分配倾向于高期望方向，同时保留不确定性探索。

- **实验技能与文本反馈**  
  当臂选定后，RecHarness 使用“实验技能”文档（包含当前最优版本、近期成功/失败编辑、验证趋势等）作为 LLM 推理的上下文，由 LLM 生成具体优化假设和可执行代码编辑。实验技能每轮自动更新，但不影响 Bandit 路由器的后验更新，保证标量反馈与文本反馈各司其职。

- **跳跃盆地机制**  
  定义近期提升速率 \( \hat{v}_t \)，若低于阈值 \( \tau \)，则视为局部饱和，激活跳跃臂进入候选池。跳跃臂产生的结构变化经最多 \( R \) 轮局部再调优后，才与跳跃前最优对比，超过 margin \( \delta_{\text{jump}} \) 时被接受，避免因结构跳变立即评估而放弃长线改进。
